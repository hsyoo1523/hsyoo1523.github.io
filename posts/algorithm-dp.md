# 다이나믹 프로그래밍 (DP)

## 핵심 아이디어

복잡한 문제를 작은 하위 문제로 나눠서, **이미 풀었던 결과를 재사용**해 전체 답을 구하는 방식.

두 가지 조건이 성립할 때 DP를 쓸 수 있어요:
1. **최적 부분 구조** — 전체 최적해가 부분 최적해로 구성됨
2. **중복 부분 문제** — 같은 하위 문제가 반복 등장함

---

## Top-Down (메모이제이션)

재귀로 내려가면서 계산 결과를 저장.

```python
memo = {}

def fib(n):
    if n <= 1:
        return n
    if n in memo:
        return memo[n]
    memo[n] = fib(n - 1) + fib(n - 2)
    return memo[n]
```

## Bottom-Up (타뷸레이션)

작은 문제부터 순서대로 채워 올라감.

```python
def fib(n):
    dp = [0] * (n + 1)
    dp[1] = 1
    for i in range(2, n + 1):
        dp[i] = dp[i - 1] + dp[i - 2]
    return dp[n]
```

---

## 대표 문제 유형

| 유형 | 예시 문제 |
|------|----------|
| 1차원 DP | 피보나치, 계단 오르기 |
| 배낭 문제 | 0/1 Knapsack |
| 문자열 DP | LCS, 편집 거리 |
| 구간 DP | 행렬 연쇄 곱셈 |

---

## 풀이 흐름

1. **점화식 세우기** — dp[i]가 무엇을 의미하는지 정의
2. **초기값 설정** — dp[0], dp[1] 등 기저 사례
3. **순서 결정** — 어떤 순서로 채워야 하는지
4. **답 찾기** — dp 배열 어디서 꺼내는지
